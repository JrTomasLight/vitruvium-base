# Витрувий для Foundry VTT

Игровая система для виртуального стола [Foundry VTT](https://foundryvtt.com/) по правилам настольной ролевой игры **«Витрувий»**. «Витрувий» — универсальная система, по которой можно создавать настольные ролевые игры в любом сеттинге.

> ⚠️ **Система в разработке.** Проект на стадии бета-теста. Возможности могут меняться, ошибки ожидаемы.

## О проекте

- **Фанатский и некоммерческий проект.** Система не продаётся и не приносит дохода.
- **Правила:** версия Beta 3.1, находится в открытом тестировании.
- **Язык:** русский.

## Требования

- Foundry VTT **v13** (Build 351). Другие версии не поддерживаются.

## Установка

Репозиторий закрытый. Поэтому встроенный установщик Foundry, который скачивает систему по ссылке на манифест, пока не сможет до него достучаться: Foundry не умеет входить в GitHub. Пока репозиторий закрыт, систему ставят и обновляют через git. Для этого нужен доступ к репозиторию.

### Через git (рекомендуется)

1. Найдите папку данных Foundry. Её путь указан на экране настройки Foundry, во вкладке «Конфигурация», в поле User Data Path. Перейдите в её подпапку `Data/systems`.
2. Откройте терминал **в папке `Data/systems`**. Папку `vitruvium` заранее не создавайте: команда создаст её сама. Её имя обязательно должно совпадать с id системы:
   ```
   git clone https://github.com/JrTomasLight/vitruvium-base.git vitruvium
   ```
   В итоге файл манифеста должен лежать по пути `Data/systems/vitruvium/system.json`, а не во вложенной папке.
3. Перезапустите Foundry. Система «Витрувий» появится в списке систем.

**Обновление:** закройте мир, выполните `git pull` в папке `Data/systems/vitruvium` и снова запустите Foundry.

### Через манифест

Этот способ заработает, только если файлы релизов станут доступны без входа в GitHub. В Foundry: **Игровые системы → Установить систему**, затем в поле «URL манифеста» вставьте:
```
https://github.com/JrTomasLight/vitruvium-base/releases/latest/download/system.json
```

### Рекомендуемые модули

- [Dice So Nice!](https://foundryvtt.com/packages/dice-so-nice) — 3D-кубики. Система добавляет в него свой кубик с символами успехов на гранях. Модуль **необязателен**: без него броски работают так же, только без анимации.

### Русский интерфейс Foundry

Сама система полностью на русском. Чтобы на русском был и интерфейс самого Foundry, установите модуль русификации ядра и выберите язык «Русский» в настройках.
